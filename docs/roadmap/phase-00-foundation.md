# Phase 00: Foundation

## Goal

Create the planning and documentation foundation for the commerce platform without creating application code.

This phase is complete. The active product roadmap now continues in
`docs/roadmap/mvp-roadmap.md`.

## Scope

Included:

- Repository structure proposal.
- Maven multi-module strategy.
- Dependency and plugin management strategy.
- Documentation structure.
- ADR structure.
- Testing strategy.
- Git and GitHub workflow.
- Docker Compose infrastructure plan.
- CI pipeline plan.
- Initial roadmap.

Excluded:

- Java application code.
- Microservice creation.
- Angular initialization.
- Docker Compose files.
- CI workflow files.
- Commits and pushes.

## Deliverables

- `README.md`
- Core docs under `docs/`
- Roadmap docs under `docs/roadmap/`
- ADR docs under `docs/adr/`

## Repository Structure Recommendation

The canonical planned repository structure is maintained in `docs/architecture.md`.

Phase 0 records the structure only. It does not approve creating all planned directories or modules.

## Exit Criteria

- Documentation foundation exists.
- Initial ADRs are recorded.
- Roadmap for the next phases is clear.
- No application code has been created.
